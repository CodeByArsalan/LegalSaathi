# Legal Saathi - Architectural Specification

## 1. Architectural Philosophy
Legal Saathi implements a modular, feature-oriented Clean Architecture designed for high performance, statutory compliance with Pakistani law, and strict maintainability.

### Key Rules:
1. **Zero Raw SQL in Controllers**: Controllers only dispatch commands or queries to Application features/services.
2. **ADO.NET + Stored Procedures**: No heavy ORM layer. All database access uses parameterized stored procedures executed through `ISqlProcedureExecutor` with asynchronous cancellation tokens.
3. **Provider Abstractions**: Third-party services (AI, SMS, Email, Payment Gateways, Document Generators) are behind interface contracts in `Application/Common/Interfaces/`.
4. **Bilingual By Design**: All domain models for templates, form fields, and generated documents store both Urdu and English representations.

---

## 2. API Layer Organization (`src/LegalSaathi.Api`)

- **Controllers/**: Thin HTTP request dispatchers returning standardized `ApiResponse<T>`.
- **Application/**:
  - `Common/`: Result wrappers, exceptions, pagination models, and service interfaces.
  - `Features/`: Feature slices (Auth, Templates, UserDocuments, Payments, AI, Reviews).
- **Domain/**:
  - `Entities/`: Pure POCO domain models (Users, Templates, UserDocuments, Payments, etc.).
  - `Enums/`: Domain enumerations (Roles, DocumentStatus, PaymentGatewayType, etc.).
- **Infrastructure/**:
  - `Data/`: `SqlConnectionFactory`, `SqlProcedureExecutor`, `DbConstants`.
  - `Security/`: JWT token generator, password hashing, claims principal extensions.
  - `Services/`: Concrete implementations and stubs for AI, payments, notifications, storage.
- **Contracts/**: DTOs for client requests and server responses.
- **Middleware/**: Centralized global exception handler, request logging, security headers.
- **Security/**: Role definitions, authorization policies, requirement handlers.

---

## 3. Database Schema Overview

The database uses Microsoft SQL Server 2022 with the following core tables:
1. `Users` - End-users, Lawyers, Corporate Admins, Super Admins.
2. `TemplateCategories` - High-level legal categories (Personal, Real Estate, Business, Vehicles).
3. `Templates` - Specific legal document templates with bilingual metadata and pricing tiers.
4. `FormFields` - Dynamic questionnaire fields associated with templates.
5. `UserDocuments` - Document instances generated by users with form answers JSON.
6. `Signatures` - In-app touch signatures, timestamps, IP addresses, and OTP verification records.
7. `Payments` - Transaction records for JazzCash, EasyPaisa, PayFast.
8. `Lawyers` - Advocate profiles, Bar Council credentials, and specialization areas.
9. `LawyerReviews` - Review requests, advocate feedback, and approval status.
10. `AIQueries` - Interaction log with OpenAI GPT-4o assistant for legal advisory.
11. `AuditLogs` - Tamper-evident immutable audit log for ETO 2002 compliance.
